# 本地 Dense 实验结果

本报告记录当前实现的可复现摘要；原始 `artifacts/`、模型缓存和 provider
响应均不提交到 Git。它们保留在执行机器上，运行 ID 为
`full-dev-*` 与 `full-final-*`。

## 设置

- 数据：STARD，处理后数据哈希
  `d2bc0bf33155184c150c400cf1b29e03230e0dfc5c0a098dac5fdb3a59020482`。
- 开发集：固定 `tune_train` 600 题；保留评估集：309 题。
- 共同设置：22 个领域按本地 `BAAI/bge-small-zh-v1.5` 相似度排序；从
  Top-4 起按文件并集动态缩减到不超过 255 份文件；每题选择 2 份文件；
  BM25 Top-1000 与 Dense Top-1000 以 RRF（常数 60）融合，最终输出 Top-10。
- Dense 后端：本地 `BAAI/bge-small-zh-v1.5`，不是 SiliconFlow BGE-M3。
  结果不得与远程 BGE-M3 运行混合比较。
- 方法二：Jev Choice 按完整领域目录中的文件 ID 和标题概率选择前 2 份文件。
- 方法三：Jev Choice 对 RRF 条文候选按“名称 + 正文”重排。

## 开发集：选择条文候选深度

仅在 600 题开发集上比较 POST 候选深度，随后冻结设置；保留集未参与选择。

| POST 候选深度 L | Recall@10 | nDCG@10 | Hit@1 | Shortlist Recall | 平均 shortlist 大小 |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 10 | 0.1221 | 0.1192 | 0.1283 | 0.1221 | 10.00 |
| 20 | 0.1286 | 0.1246 | 0.1350 | 0.1337 | 19.83 |
| 30 | **0.1380** | **0.1309** | **0.1417** | **0.1461** | 28.69 |

因此冻结 `L=30`，用于后续保留集 POST 评测。

## 保留集结果

评测包含 309 道保留问题；数值均为逐题宏平均。

| 方法 | Recall@10 | nDCG@10 | Hit@1 | 领域标准条文保留率 | 文件标准条文保留率 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 方法一：标题相似度基线 | 0.1348 | 0.1181 | 0.1036 | 0.8569 | 0.1767 |
| 方法二：Jev 前置文件 Choice | **0.4941** | **0.4074** | **0.3495** | 0.8569 | **0.7588** |
| 方法三：Jev 后置条文重排（L=30） | 0.1438 | 0.1411 | 0.1586 | 0.8569 | 0.1767 |

方法二相对基线的 nDCG@10 提升为 0.2893，且文件层标准条文保留率由
0.1767 提升到 0.7588。这说明当前设置下的主要收益来自文件级 Choice，
而不是检索后的条文重排。方法三也改善了三个最终指标，但幅度较小。

## 成本记录

本地 Dense 向量生成没有远程 API 费用。provider ledger 记录的 Jev 成本是
运行时预留/估算值，而非账户最终账单：保留集 PRE 为 `$0.00924`，POST 为
`$0.00927`。开发集主比较中 PRE 为 `$0.01800`，冻结的 POST L=30 为
`$0.01683`。实际费用以 provider 账单和输入 token 为准。

## 局限

- 本结果是本地 bge-small Dense 变体，不能宣称为远程 BGE-M3 的结果。
- 当前报告未计算问题级 paired bootstrap 置信区间；在作显著性结论前应补充。
- 领域筛选本身限制了可达召回：保留集的领域标准条文保留率为 0.8569。
